Connect to GitHub

Create a fine-grained personal access token scoped only to this repository:

  1. Go to GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Repository access: Only select repositories → carlos-portfolio
  3. Permissions → Repository permissions → Contents: Read and write
  4. Generate, copy the token, and paste it below

The token is stored only in this browser (localStorage) and is sent only to api.github.com — never to Claude or anyone else. Remove it any time with "Forget token" below, or revoke it on GitHub.
